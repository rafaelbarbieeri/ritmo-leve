# Ritmo Leve — Blog de Life Style

Blog estático desenvolvido para a atividade **AOP2** (UVV). O tema escolhido foi **Life Style**: bem-estar, alimentação, casa e rotina.

## Páginas

| Página | Arquivo | Conteúdo |
| --- | --- | --- |
| Home | `index.html` | Apresentação do blog, como ele funciona e os 3 conteúdos em destaque (imagens com link) |
| Bem-Estar | `bem-estar.html` | Sono, respiração, movimento e equilíbrio digital |
| Alimentação | `alimentacao.html` | Prato colorido, receita, marmitas e feira da estação |
| Casa & Rotina | `casa-e-rotina.html` | Manhãs, destralhe, planejamento semanal e cantinho de calma |
| Contatos | `contatos.html` | Formulário (demonstrativo), informações de contato e perguntas frequentes |

## Estrutura

Todas as páginas usam a estrutura básica do HTML: `head`, `body`, `header` (com o `nav` de 5 links), `main` e `footer`.

```
ritmo-leve/
├── index.html
├── bem-estar.html
├── alimentacao.html
├── casa-e-rotina.html
├── contatos.html
├── css/style.css
├── js/script.js
└── img/  (ilustrações SVG originais)
```

## Tecnologias

- HTML5 semântico
- CSS3 (layout com Grid/Flexbox, responsivo para celular)
- JavaScript (apenas a validação do formulário de contato)
- Fontes: Fraunces e Instrument Sans (Google Fonts)
